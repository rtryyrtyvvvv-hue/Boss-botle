# Boss Bottle — ilkin demo

Bu paket brauzerdə işləyən ilkin prototipdir:
- 12 oyunçu masası
- şüşənin animasiyalı fırlanması
- təsadüfi oyunçu seçimi
- coin sistemi
- gündəlik pulsuz bonus
- demo admin bonus düyməsi

## Açmaq
`index.html` faylını Chrome-da aç.

## Telegram-a çevirmək
Növbəti mərhələdə bunu Telegram Mini App-a bağlamaq üçün:
1. BotFather ilə bot yaradılır.
2. Bu web tətbiqi HTTPS domeninə yerləşdirilir.
3. Botun Mini App düyməsi həmin domenə bağlanır.
4. Coin və admin hüquqları serverdə saxlanılır.

Vacib: Bu HTML demo-da admin qoruması real təhlükəsizlik deyil. Real versiyada yalnız sahibin Telegram user ID-si serverdə admin kimi yoxlanmalıdır.
